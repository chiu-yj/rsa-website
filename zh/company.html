品牌理念 / 專案背景

讓科技，
幫助我們 理解環境。

RSA 希望讓建築環境分析走出只有專家才能解讀的介面，使設計者與研究者更容易對話、比較與決策。

01 / 專案使命

從複雜數據，
走向清楚理解。

住宅基地環境分析 Residential Site Analyzer（RSA），源自建築領域的獨立研究與軟體開發實作。

長期目標是讓日照、風環境與熱舒適等分析結果，成為更易理解、更可追溯的決策支援資訊。RSA 不將漂亮的視覺效果等同科學可信度，而是希望用持續驗證建立信任。

RSA / 願景
「真正有價值的環境分析，應讓使用者知道 為什麼、依據什麼，以及還不知道什麼。」

02 / 專案開發者

獨立開發，
長期累積。

邱禹鈞 Yu-Jyun Chiu

研究負責人 · 獨立開發者

RSA 由邱禹鈞主導開發，並結合在國立高雄大學建築學系研究所的學術研究方向，探索住宅基地環境證據、資訊轉譯與設計決策。

目前以獨立研究原型的形式開發，並非已註冊公司，也不代表學校正式提供或認證的服務。

03 / 核心原則

01 / 證據

04 / 專案狀態聲明

可以有完整品牌，
也必須如實說明。

RSA 目前不是已成立的公司。RSA 具備網站、獨立網域信箱及真實軟體研發成果，但未有公司正式登記，不宣稱付費客戶、員工團隊、外部募資、正式商用產品或校方授權。RSA Studio 與 RSA Intelligence 屬未來產品概念；國立高雄大學為開發者研究背景，不代表學校背書。
RSA 是已登記成立的新創公司嗎？

不是。目前 RSA 是獨立開發的研究原型與未來品牌構想。

網站上的系統畫面是真的嗎？

平台展示的五類介面截圖來自真實 RSA 開發環境，但功能顯示不代表整體科學精度或產品穩定度已完成驗證。

Claude AI 功能已經上線了嗎？

尚未。Claude API 整合是後續規劃的研究方向。

RSA 與國立高雄大學的關係是什麼？

此專案與開發者個人的建築學術研究有關，並非校方正式授權、經營或背書的產品。
