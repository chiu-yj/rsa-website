## Stack

Plain static HTML, one CSS file and one small JS file. English at `/`, Traditional Chinese at `/zh/`.
Pages are generated by `python3 tools/build.py` from `tools/content.py`; the generated HTML is committed, so GitHub Pages needs no build step.
Served by GitHub Pages from the repository root; `CNAME` must stay `rsa-analyzer.com`.

```
index.html            Home
work.html             Work index (filterable) + project register
project-*.html        Five case studies (vision, corner, encounter, futian, datong)
platform.html         Residential Site Analyzer / RSA Studio (concept) / RSA Intelligence (planned)
zh/                   Traditional Chinese versions of the pages above
tools/                build.py + content.py (bilingual source)
assets/css/site.css   Design tokens, type, grid, components
assets/js/site.js     Mobile menu, reveal-on-scroll, tabs, work filters, cover sun
assets/img/work/      Original design renders (2048 px) + 960/ thumbnails
assets/img/rsa/       Real RSA prototype screenshots (dev build)
favicon.svg  CNAME  ASSETS.md (image sources & rights to confirm)
```

All pages are redesigned in English and Traditional Chinese: Home, Work, five case studies, Platform, Research, About (`company.html`), Contact, Privacy, plus `404.html`, `sitemap.xml` and `robots.txt`.

When merging into `main`, old files that no longer exist here (for example `solutions.html`, `project-fengge.html`) can be deleted or left; nothing links to them.

## Design system

- **Palette:** ink `#111110`, paper `#f2f1ee`, greys, and one orange `#ff5a1f` used as a
  redline (marks, cuts, primary button) — never for decoration. Small orange text uses
  `#b8400f` for contrast.
- **Type:** Archivo (variable width; condensed 62 for display, 100 for text, 125 for the
  wordmark) and IBM Plex Mono for sheet numbers, captions and labels. Chinese falls back
  to Noto Sans TC / PingFang TC.
- **Concept:** the site reads like a drawing set — sheet numbers, title blocks, a
  section-cut line, a drawing register for the work.
- **Status legend (keep it honest):** every claim about RSA carries one stamp:
  `stamp--real` (working prototype / real screenshot), `stamp--explore` (exploratory,
  not validated), `stamp--record` (historical, version-specific), `stamp--planned`
  (not built yet), `stamp--concept` (illustration only). `stamp--work` marks
  authorship of design work.

## Content rules

- Design work is credited to its real author and role. Academic projects are individual
  academic designs; Futian (福田案) and Datong are prior employment for a former employer.
  **None were RSA contracts or analysed with RSA.**
- r42 / r44 figures are archived, version-specific records — never current certification.
- Wind is exploratory, not CFD. UTCI is a research view. Studio is a concept;
  Intelligence (Claude API) is planned and not deployed.
- Do not publish personal phone numbers or private email addresses.
  Public contact is `research@rsa-analyzer.com`.

## Deploy

Work on a branch (e.g. `design/redesign-v9`), open a Pull Request into `main`, review
desktop / tablet / mobile and `/zh/`, then merge. GitHub Pages publishes on merge.
DNS (Cloudflare) and email (Zoho) need no changes.
